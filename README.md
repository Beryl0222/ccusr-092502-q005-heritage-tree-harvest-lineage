# 古树采后责任谱系

西溪湿地扁柿、火柿、方柿成熟季的后端责任谱系：为七千多棵古树的树木、品种、年度评估、可采范围、作业小组、称重批次、损伤观察、果品去向与后续修复建立**不可混淆的编号与可追溯谱系**，在向游客开放体验的同时守住年度负荷。

## 核心规则

1. **编号不可混淆**：不同聚合使用不同前缀（`TREE-`、`CV-`、`CREW-`、`ASMT-`、`WIN-`、`LOT-`、`WGH-`、`XFER-`、`DAM-`、`CARE-`、`QUAR-`、`EVT-`），编号形如 `LOT-2026-000042`，序号按（类型，年份）单调续发，重启后由事件流回放恢复水位。
2. **业务事实只追加**：事件一经接收永不原地改写；更正、改派一律以后续事件表达（`OBSERVATION_CORRECTED`、`CARE_PLANNED` 顶旧计划）。
3. **离线称重重传幂等**：秤端称量号 `WGH-*` 即事件号。同号同内容（含数值与秤端时间，SHA-256 指纹）重传直接返回首次事件，不重复入账；**同号不同内容不允许改写，先写 `LOT_QUARANTINED` 隔离批次**，冻结后续称重与去向，等待人工 `release_lot` 或 `discard_lot`。
4. **果品数量守恒、去向唯一**：一个批次只能确定一个去向（游客采摘 / 科研留样 / 公益赠送），重复指定不同去向被拒绝；交接数量不得超过批次净重；废弃批次计入损耗而非任何去向。守恒口径：`采收净重 = 已交接 + 已隔离 + 已废弃`。
5. **树势异常可暂停**：`TREE_SUSPENSION_TOGGLED` 只阻断暂停之后的新作业；**已完成的交接与原责任人完整保留**，恢复后可继续。
6. **观察纠正只局部重算**：纠正一次观察时，仅重算相关树木该年度的负荷投影与修复计划（计划被取代或取消），其它树木与年度不动；原始观察与纠正轨迹都留在谱系中。
7. **重启继续待办**：待处理的隔离批次（`pending_quarantines`）与修复计划（`pending_care`）全部从事件流恢复，服务重启不丢。

## 模块结构

| 文件 | 职责 |
| --- | --- |
| `contracts/domain.json` | 聚合类型、编号前缀、事件名称、去向枚举、基础信封 |
| `src/envelope.py` | 共用事件信封与时间格式校验，不含业务流程 |
| `src/ids.py` | 统一编号规则、编号反查类型、按（类型，年份）的序号水位 |
| `src/events.py` | 事件构造与业务内容指纹（用于幂等/冲突判定） |
| `src/store.py` | JSONL 追加式事件存储：fsync、event_id 去重、聚合版本、回放 |
| `src/projection.py` | 由事件流装配的读模型：年度负荷、树木谱系、守恒报告、闭环核对 |
| `src/service.py` | 应用服务：全部业务不变量、幂等、隔离、暂停、纠正重算、待办恢复 |

## 两类使用视角

- **养护员（顺谱系向下）**：`tree_lineage(tree_id)` 从一棵树追到每一年度的评估、负荷、每个批次的称重、隔离、去向、交接链、损伤观察（含纠正记录）与修复。
- **管理者（核守恒与闭环）**：`conservation_report(year)` 按树×年核对果品数量守恒、按去向汇总，并列出未关闭批次、隔离中批次与未完成修复；`lot_closure(lot_id)` 核对单批次的去向、数量、责任链与损伤修复闭环。

## 主要业务流程

```
品种/小组/树木登记 → 年度评估(TREE_ASSESSED, 容量)
  → 划定可采范围(HARVEST_WINDOW_OPENED, ≤ 容量)
  → 建批次(LOT_CREATED, 树+小组+范围)
  → 离线称重(LOT_WEIGHED, WGH 幂等/冲突隔离/超范围隔离)
  → 确定唯一去向(DESTINATION_ASSIGNED)
  → 责任交接(CUSTODY_TRANSFERRED, 数量≤净重, 交出人须为当前责任人)
  → 损伤观察(DAMAGE_OBSERVED) ⇄ 纠正(OBSERVATION_CORRECTED)
  → 修复计划(CARE_PLANNED，随观察自动重算/取代/取消) → CARE_COMPLETED
```

隔离分支：`LOT_QUARANTINED` → 人工核查 → `LOT_RELEASED`（继续流程）或 `LOT_DISCARDED`（计入损耗守恒，已交接的批次不可废弃）。

## 测试与构建

```bash
python3 -m unittest discover -s tests
python3 -m compileall -q src tests
```

- `tests/test_contract.py`：基础事件信封合同。
- `tests/test_lineage.py`：编号、称重幂等、指纹冲突隔离、超范围隔离、去向唯一、交接守恒、暂停与历史责任、纠正局部重算、重启恢复、树木谱系与损耗守恒共 14 组行为。

只依赖 Python 3.11 标准库，可在单个 Linux 应用容器中直接执行。
